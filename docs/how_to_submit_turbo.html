Resolution ... != 100mWrong pixel sizeEnsure output is 100m resolution

X px inside template's valid region are not finiteNaN inside scored areaRun: python scripts/sanitize_submission.py --pred FILE --write
Size mismatchWrong dimensionsMust be exactly 3292×3730

Auto-Fix with Sanitizer

If your file has NaN or format issues, the sanitizer can fix it:

python scripts/sanitize_submission.py --pred YOUR_FILE.tif --write

This ensures:

  • All pixels in valid region are finite and in [0, 1]
  • All pixels outside valid region are NaN
  • GDAL_NODATA tag matches template
  • Values are clipped to [0, 1]

The Distance-Weighted Tversky Index (DTI) rewards:

  • True Positives: Correctly predicted fault pixels (+1.0 weight)
  • False Positives: Incorrectly predicted non-fault pixels (-0.2 weight)
  • False Negatives: Missed fault pixels (-0.8 weight)

Note: The metric uses a 300m (3-pixel) triangular kernel, so predictions near true faults get partial credit.

Don't worry! Try these steps:

Troubleshooting

Common Issues and Solutions

❌ "Predicted values must be in range [0, 1]"

Cause: Your file has NaN values or values outside [0,1] within the valid (scored) region.

Solution:

# Run the sanitizer
python scripts/sanitize_submission.py --pred YOUR_FILE.tif --write

# Then validate
python scripts/validate_submission.py --pred YOUR_FILE.tif

Prevention: All TURBO-generated files are automatically sanitized, so this should not occur with files from this system.
